# Bingo Battle Royale

Multiplayer bingo game 

## Setup

### Backend
```bash
cd backend
npm install
npm run dev
```
Server runs on `http://localhost:5000`

### Frontend
```bash
cd frontend
npm install
npm start
```
App runs on `http://localhost:3000`

## How to Play

1. Enter your name
2. Get matched with other players
3. Numbers are called randomly
4. Mark numbers on your card
5. First to get 5 in a row wins and earns 10 points!

## Features

✅ Expert-level AI bots you can't distinguish from real players
✅ Hidden multiplayer matching
✅ Points-based leaderboard system
✅ Real-time game updates
✅ Classic 5x5 bingo cards
